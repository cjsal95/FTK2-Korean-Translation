# 👑 For The King II - 유저 한글 오역 수정 패치 & 번역 툴

스팀(Steam) 게임 **《포 더 킹 2 (For The King II)》**의 어색한 공식 한글 번역을 직접 수정하고 배포할 수 있도록 도와주는 유저 한글 패치 및 파이썬(Python) 기반 유니코드 변환 툴셋입니다.

이 프로젝트는 개발사가 숨겨둔 언어 데이터 시스템을 분석하여 오역을 바로잡고, 다른 모더들이나 유저들이 깨짐 현상 없이 한글 패치 작업을 진행할 수 있도록 돕기 위해 제작되었습니다.

저는 DLC가 없어요! DLC 관련 번역은 제가 알 수 없습니다.

---

## 🛠️ 주요 기능

- **유니코드 이스케이프 디코더 (`FTK2_Decoder.py`):** 코드(`\uXXXX`)로 박혀있는 게임 원본 JSON을 사람이 읽을 수 있는 한글 파일로 변환합니다.
- **원본 포맷 인코더 (`FTK2_Encoder.py`):** 유저가 직접 수정한 한글 파일을 게임 엔진이 인식할 수 있는 유니코드 이스케이프 포맷으로 되돌립니다.

---

## 📂 파일 구성 및 설치 경로

### 1. 파일 구성
- `FTK2_Decoder.py`: 유니코드 ➡️ 한글 변환 스크립트
- `FTK2_Encoder.py`: 한글 ➡️ 유니코드 원본 포맷 변환 스크립트
- `ko.json`: 한글 번역이 간략히 수정된 파일 (For The King II\For The King II_Data\StreamingAssets\Assets\Configs\JSON~\Langs 에 덮어쓰기 하세요.)

### 2. 게임 내 언어 파일 경로
스팀 라이브러리에서 게임 우클릭 ➡️ `관리` ➡️ `로컬 파일 찾아보기`를 누른 뒤 아래 경로로 이동하세요.
> `For The King II_Data\StreamingAssets\Assets\Configs\JSON~\Langs`

## 🚀 사용 및 모딩 방법 (가이드)

### 방법 A. 제공된 한글 패치만 바로 적용하고 싶을 때
1. 본 레포지토리에서 변환이 완료된 **`ko.json`** 파일을 다운로드합니다.
2. 위에서 안내한 **게임 내 언어 파일 경로**에 다운로드한 파일을 그대로 덮어씌웁니다.
3. 게임을 실행하여 정상적으로 적용되었는지 확인합니다. (기존 `ko.json` 파일은 백업해두는 것을 추천합니다.)

### 방법 B. 직접 번역을 수정하고 적용하고 싶을 때 (파이썬 사용)
1. 파이썬(Python 3.x)이 설치되어 있는지 확인합니다.
2. `ko_translated.json` 파일을 메모장이나 Notepad++, VS Code 등으로 열어 원하는 문장을 한글로 수정합니다.
   * *⚠️ 주의: 왼쪽의 `"KEY_NAME"` 코드는 절대 건드리지 말고 오른쪽 한글만 수정하세요! 문장 끝의 쉼표(,) 사수가 중요합니다.*
3. 수정이 완료되면 터미널(CMD)을 열어 아래 명령어를 실행합니다.
   ```bash
   python FTK2_Encoder.py
